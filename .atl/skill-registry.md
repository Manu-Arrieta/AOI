### Artifact Store

Artifacts are stored in `.tasks/{FEATURE_NAME}/TASK-YYYY-NNN/`:

```
.tasks/{feature-name}/
├── feature.md                         ← Feature metadata
├── TASK-YYYY-NNN/
│   ├── context.md                     ← Task state
│   ├── proposal.md                    ← /sdd-new
│   ├── requirement.md                 ← @functional-analyst
│   ├── spec.md                        ← /speckit.specify (via /sdd-ff)
│   ├── design.md                      ← /speckit.plan (via /sdd-ff)
│   ├── tasks.md                       ← /speckit.tasks (via /sdd-ff)
│   ├── implementation-plan.md         ← @solution-architect
│   ├── relations.json                 ← Explicit task ↔ resource links
│   ├── iterations/                    ← Implementation logs
│   ├── verify-report.md               ← /sdd-verify
│   ├── functional-docs.md             ← @documentation-analyst
│   └── archive-report.md              ← /sdd-archive
```

### Optional Resource Store

Reusable context lives in `.resources/` and remains opt-in during task
construction:

```text
.resources/
├── constitution.md                    ← Local subtree contract
├── userstories/                       ← Reusable user-story context
└── workflows/                         ← Component interaction definitions
```

### Internal Dashboard Runtime

The managed workspace also provisions an internal Nuxt runtime under
`aoi_apps/agentic-ops-dashboard/`, mirrored in
`scaffold/aoi_apps/agentic-ops-dashboard/`.

Commands:

- `pnpm --dir aoi_apps/agentic-ops-dashboard dev`
- `pnpm --dir aoi_apps/agentic-ops-dashboard test`
- `pnpm --dir aoi_apps/agentic-ops-dashboard exec nuxt prepare`
- `pnpm --dir aoi_apps/agentic-ops-dashboard build`

Boundaries:

- Reads `.tasks/registry.md`, task artifact directories, and optional
  `.resources/` content.
- Uses `.tasks/{feature}/TASK-YYYY-NNN/relations.json` as the canonical explicit
  task-to-resource relation record.
- Restricts writes to governed `.resources/` operations only.
