# AOI v0.1.0

The first public template baseline for AOI (Agentic Operational Infrastructure).

## What is included

- Hardened setup with mandatory `icm` verification.
- Non-blocking `rtk` installation policy.
- Mandatory dashboard runtime checks for Node `>=20.19.0` and `corepack` or `pnpm >=11.3.0`.
- Workspace-local `.vscode/mcp.json` registration for `icm serve --compact`.
- Internal Nuxt dashboard runtime for operational visibility.
- Governed versioned-memory sync and portable memory-bundle workflows.
- Clean public baseline with empty task registries, no active sandboxes, and no active versioned-memory workspace.

## Why this tag matters

`v0.1.0` is the first GitLab-ready AOI baseline for using the repository as a public template or as an installer into another project.
