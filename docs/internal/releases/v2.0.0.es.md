# AOI v2.0.0

Fecha: 2026-08-25

AOI v2.0.0 marca la evolución mayor de Agentic Operational Infrastructure: arquitectura de bootstrapper de ultra-bajo consumo de tokens, matriz de datos TanStack Table en el Dashboard, protocolo Zero-Disabled-Tools y aislamiento quirúrgico de contexto para subagentes.

## Highlights

- **Arquitectura de Bootstrapper Puro y Ligero**: Eliminación completa de capas sintéticas redundantes, reduciendo el tamaño del repositorio en un **82.6%** (245 archivos totales) y el volumen de código en un **94.1%** (~8,500 LOC).
- **Dashboard de Operaciones con TanStack Table**: Nueva vista de alta densidad con ordenamiento, filtrado multifactorial y scroll virtualizado para el registro de tareas gobernadas.
- **Protocolo Zero-Disabled-Tools**: Verificación obligatoria al inicio de sesión y auto-activación/reactivación en caliente de los 7 grupos de herramientas MCP (ICM + Codebase Memory).
- **Aislamiento Quirúrgico de Subagentes**: Integración obligatoria de `scripts/subagent-context/sanitize-subagent-payload.mjs` para reducir en un 80% el consumo de tokens en la delegación de micro-agentes (`@frontend-developer`, `@backend-developer`, `@devops-engineer`).
- **Optimización de Alcance de Instrucciones (`applyTo` Scoping)**: Segmentación fina de reglas agénticas, reduciendo más del 60% la sobrecarga de tokens base por turno de conversación.
- **Flujo SDD Refinado**: Prompts `/sdd-new`, `/sdd-ff`, `/sdd-apply`, `/sdd-verify` y `/sdd-archive` con compuertas de calidad deterministas, inferencia de contratos de interfaces y ciclo TDD (Red-Green-Refactor) obligatorio.
- **Gobernanza de Scaffold Reforzada**: Validación de paridad espejo 100% byte-a-byte automatizada con compuerta de CI en `.github/workflows/aoi-gate.yml`.

- `Automated Test Suite`: **102 / 102 tests aprobados en ~1.2s**.
- `Dashboard Production Build`: **Nuxt 4 / Nitro compilado limpiamente**.
