# AOI v2.0.0

Date: 2026-08-25

AOI v2.0.0 marks a major milestone for Agentic Operational Infrastructure: ultra-low token consumption bootstrapper architecture, TanStack Table data matrix in the Dashboard, Zero-Disabled-Tools protocol, and surgical context isolation for subagents.

## Highlights

- **Lean & Pure Bootstrapper Architecture**: Complete removal of synthetic mock layers, reducing repository file count by **82.6%** (245 total files) and codebase size by **94.1%** (~8,500 LOC).
- **Operations Dashboard with TanStack Table**: High-density task matrix view with multi-column sorting, filtering, and virtualized scrolling for the governed task registry.
- **Zero-Disabled-Tools Protocol**: Mandatory session start verification and continuous hot-reactivation of all 7 MCP tool groups (ICM + Codebase Memory).
- **Surgical Subagent Context Isolation & TOON Serialization**: Mandatory integration of `scripts/subagent-context/sanitize-subagent-payload.mjs` with native TOON serialization support (`scripts/subagent-context/toon-serializer.mjs`), delivering up to 80-90% token reduction during micro-agent delegation.
- **MCP Compression Gateway Proxy**: Configuration of `@atlassian-labs/mcp-compressor` (`scripts/mcp-gateway/`) with compact TypeScript signatures for Tier 1 high-frequency tools and *Progressive Disclosure*, reducing schema overhead by up to 85%.
- **Relevance-Contrast Engine & Mechanical Set Union**: Calibrated context injection (`scripts/sdd-lifecycle/context-arranger.mjs`) and deterministic defect consolidation (`scripts/sdd-lifecycle/mechanical-verify-union.mjs`) in `/sdd-verify` with 0 synthesis tokens.
- **Instruction Scope Optimization (`applyTo` Scoping)**: Fine-grained pattern matching on agent instructions, eliminating over 60% of baseline token overhead per conversation turn.
- **Refined SDD Lifecycle**: Prompts `/sdd-new`, `/sdd-ff`, `/sdd-apply`, `/sdd-verify`, and `/sdd-archive` with deterministic quality gates, contract inference, and mandatory TDD (Red-Green-Refactor).
- **Strengthened Scaffold Governance**: 100% byte-for-byte scaffold mirror parity enforced with CI gate workflow in `.github/workflows/aoi-gate.yml`.
