# AOI v0.1.0

La primera baseline pública de la plantilla de AOI (Agentic Operational Infrastructure).

## Qué incluye

- Setup endurecido con verificación obligatoria de `icm`.
- Política no bloqueante para la instalación de `rtk`.
- Chequeos obligatorios del runtime del dashboard para Node `>=20.19.0` y `corepack` o `pnpm >=11.3.0`.
- Registro local `.vscode/mcp.json` para `icm serve --compact`.
- Runtime interno en Nuxt para visibilidad operativa.
- Flujos gobernados de sincronización de memoria versionada y bundles portables de memoria.
- Baseline pública limpia con registries de tareas vacíos, sin sandboxes activas y sin workspace activo en memoria versionada.

## Por qué importa este tag

`v0.1.0` es la primera baseline lista para GitLab de AOI, tanto para usar el repositorio como plantilla pública como para instalarlo sobre otro proyecto.
