# AOI v0.1.0

Fecha: 2026-05-28

AOI v0.1.0 marca la primera baseline pública de la plantilla de Agentic Operational Infrastructure.

## Highlights

- Se rebrandió el proyecto público como AOI (Agentic Operational Infrastructure).
- Se publicó el repositorio AOI en GitLab y se etiquetó la baseline como `v0.1.0`.
- Se endureció el setup para que `icm` sea obligatorio y verificable durante la instalación.
- `rtk` sigue recomendado pero no bloqueante cuando su instalación falla.
- Se forzaron los prerrequisitos del runtime del dashboard en lugar de saltearlos en silencio.
- Se agregó el registro local `.vscode/mcp.json` para `icm serve --compact` tanto en la raíz como en el scaffold.
- Se incluye el dashboard interno en Nuxt como runtime de primera clase para visibilidad operativa.
- Se incluyen los flujos gobernados de sincronización de memoria versionada y exportación/importación de bundles de memoria.
- El repositorio público quedó reiniciado a un estado inicial limpio con registries de tareas vacíos, sin sandboxes activas y sin workspace activo en memoria versionada.

## Superficies Incluidas

- Scripts de setup y teardown para macOS/Linux y Windows.
- Definiciones de agentes para Copilot.
- Prompts SDD basados en Spec-Kit e instrucciones del workflow.
- Runtime del dashboard interno en `aoi_apps/agentic-ops-dashboard`.
- Runtime scaffold para instalaciones downstream.
- Scripts de sincronización de memoria en `scripts/memory-sync/`.

## Comportamiento Esperado de la Baseline

- AOI puede usarse como repositorio plantilla o como instalador sobre otro proyecto.
- `icm` es obligatorio para que el setup complete correctamente.
- `rtk` mejora la eficiencia de tokens pero no debe bloquear la instalación.
- El runtime del dashboard es obligatorio y requiere Node `>=20.19.0` más `corepack` o `pnpm >=11.3.0`.

## Verificación Recomendada Post-Tag

- Ejecutá el smoke plan externo en [docs/internal/verification/external-smoke-plan.es.md](../verification/external-smoke-plan.es.md).
- Usá el cuerpo breve listo para pegar en [docs/internal/releases/v0.1.0.gitlab-release.es.md](v0.1.0.gitlab-release.es.md).
- Creá una GitLab Release desde el tag `v0.1.0` si querés un artefacto visible en la UI además del tag.

## Notas de la Release

- Esta release quedó publicada como baseline por tag de Git. No se creó automáticamente un objeto GitLab Release desde el entorno local.
