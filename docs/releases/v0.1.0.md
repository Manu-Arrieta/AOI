# AOI v0.1.0

Date: 2026-05-28

AOI v0.1.0 marks the first public template baseline for Agentic Operational Infrastructure.

## Highlights

- Rebranded the public project as AOI (Agentic Operational Infrastructure).
- Published the AOI repository to GitLab and tagged the baseline as `v0.1.0`.
- Hardened setup so `icm` is mandatory and verified during installation.
- Kept `rtk` recommended but non-blocking when installation fails.
- Enforced the dashboard runtime prerequisites instead of silently skipping them.
- Added workspace-local `.vscode/mcp.json` registration for `icm serve --compact` in the root project and scaffold.
- Shipped the internal Nuxt dashboard as a first-class runtime for operational visibility.
- Included governed versioned-memory sync and portable memory-bundle workflows.
- Reset the published repository to a clean starter state with empty task registries, no active sandboxes, and no active versioned-memory workspace.

## Included Runtime Surfaces

- Setup and teardown scripts for macOS/Linux and Windows.
- Copilot and Antigravity agent definitions.
- Spec-Kit driven SDD prompts and workflow instructions.
- Internal dashboard runtime under `apps/agentic-ops-dashboard`.
- Scaffolded workspace runtime for downstream installations.
- Memory sync scripts under `scripts/memory-sync/`.

## Intended Baseline Behavior

- AOI can be used as a template repository or as an installer into another project.
- `icm` is required for a successful setup.
- `rtk` improves token efficiency but should not block installation.
- The dashboard runtime is mandatory and requires Node `>=20.19.0` plus `corepack` or `pnpm >=11.3.0`.
